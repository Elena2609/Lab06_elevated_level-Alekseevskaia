# ПР6. Ответы на контрольные вопросы

### 1. Чем void -метод отличается от метода, объявленного с типом возврата (например, int )? 

* void - метод просто что-то делает (печатает, считает) и ничего не отдает. Его результат нельзя положить в переменную. 

* Метод с возвратом - вычисляет и отдает результат через return. Этот результат можно записать в переменную или сразу использоватью

### 2. Что происходит с выполнением метода в момент срабатывания return ?

Метод сразу заканчивается. Код после return внутри метода уже не выполнится. Если return стоит внутри if, то сработает только та ветка, до которой дошло выполнение.

### 3. Что такое перегрузка методов и по каким признакам компилятор выбирает нужную перегрузку при вызове?

Перезагрузка - это несколько методов с одинаковым именем, но разными параметрами(другое количество или другие типы).

Компилятор смотрит на аргументы при вызове (сколько их и какого они типа) и сам выбирает подходящий метод.

### 4. Можно ли перегрузить метод, если у двух версий совпадают все параметры, а различается только тип возвращаемого значения? Почему?

Нельзя. При вызове компилятор не поймет, какой из двух методов брать - аргументы подходят к обоим, а на тип возврата он не смотрит. Будет ошибка

### 5. Приведите свой пример (не из этой работы), когда логично разбить один большой кусок кода на два отдельных метода.

Например, проверка и вывод резульатат игры. Сначала один метод определяет победителя по результатам, а другой метод, вызывая первый1 метод выводит результат на экран. Это удобно, например, чтобы сохранить историю игр и сравнить с прошлым результатом.

### 6. Что означает, когда один метод вызывает внутри себя другой метод? Как это связано с идеей переиспользования кода?

Метод вызывает другой метод, когда внутри его тела стоит вызов другого метода. 

Связь с переиспользованием: Метод-помощник пишется один раз, но используется и внутри других методов, и напрямую, поэтому его логику не нужно копировать в разные места программы. Если понадобится что-то поменть в помощнике, исправление сразу подействует во все местах, и код становиться проще читать.
